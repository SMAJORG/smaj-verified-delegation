# Original SMAJ PI HUB service artwork

These PNG files are copied unchanged from the independent `SMAJORG/smajpihub` repository, under `frontend/public/assets/`.

The mapping in `components/ServiceIcon.tsx` follows Hub's `frontend/src/components/ServiceArt.tsx` and `frontend/src/content/serviceCatalog.ts`: Store, Jobs, Education, Health and Transport use their standalone images; the remaining ten services use the original 5-column, 3-row `smaj-service-atlas.png` with the same background positions and sizing.

Keep the original colors and designs. Do not replace these files with generic or regenerated icons. Local copies keep the two applications independently deployable without runtime requests to the Hub.
